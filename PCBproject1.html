4-Bit Adder / Accumulator PCB

Project Goal

The goal of this project was to finish a simple 4-bit adder.

Documentation/notes

View my notes

Architecture

The design uses two 4-bit registers and a 4-bit binary adder. One register stores a manually entered value while the accumulator stores the running result.

PCB Design

The schematic and PCB were designed in KiCad. The board uses front and back copper layers, through-hole components, a ground plane, decoupling capacitors, manual control buttons, and LEDs.

Current Status

The schematic, PCB routing, design-rule checks, 3D inspection, Gerber files, and drill files have been completed. The next stage is PCB fabrication, soldering, and hardware testing.
